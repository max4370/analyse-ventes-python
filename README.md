# Analyse des ventes avec Python et SQL

## Présentation du projet

Ce projet a été réalisé dans le cadre d'un exercice de formation Simplon.

L'objectif est d'analyser les ventes d'une entreprise afin de mieux comprendre son activité commerciale et de faciliter la prise de décision.

## Technologies utilisées

- **Python** : traitement et analyse des données.
- **Pandas** : manipulation des données.
- **Plotly Express** : création de graphiques.
- **SQL** : analyse des ventes à partir de requêtes.
- **Git et GitHub** : gestion des versions et partage du projet.

## Analyses réalisées

- Calcul du chiffre d'affaires total.
- Analyse des ventes par produit.
- Analyse des ventes par région.
- Calcul du chiffre d'affaires par produit.

## Visualisations

Le projet contient des graphiques HTML interactifs :

- `ventes-par-produit.html`
- `ventes-par-region.html`

## Exécution du projet

Installer les dépendances :

```bash
pip install pandas plotly
```

Exécuter le programme :

```bash
python script.py
```
